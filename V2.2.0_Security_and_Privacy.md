## 3. Public/Private Boundary Enforcement

### 3.1 Boundary Rules (Reaffirmed from V2.1.0)

| Direction | Allowed | Prohibited |
|-----------|---------|------------|
| **Public → Private** | Repository metadata (description, topics, license, README summary) | Private source code, internal architecture, release plans, confidential metrics, private roadmap, owner/maintainer details |
| **Private → Public** | Nothing without explicit promotion review (WP2) | Any private information, even inadvertently shared |
